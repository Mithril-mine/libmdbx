## Примеры

Этот набор примеров будет пополняться, большинство примеров одновременно являются публично доступными тестами.

### C API
[`example-mdbx.c`](example-mdbx.c) — пример использования C API.
Однако настоятельно рекомендуется использовать современный [C++ API](https://libmdbx.dqdkfa.ru/docs/en/reference/api/group__cxx__api.html): он требует меньше
усилий и защищает от многих ошибок, связанных с утечками ресурсов.

### Berkeley DB
Если вы уже использовали Berkeley DB, полезно сделать построчное сравнение [`example-mdbx.c`](example-mdbx.c) и файла [`sample-bdb.txt`](sample-bdb.txt).

## Примеры учебника (docs/{ru,en}/textbook)

Сценарии S01–S47 из учебника по libmdbx (`docs/ru/textbook/`): по одной
самодостаточной программе на сценарий, плюс сквозной проект `config-store`
(растущие срезы 02–12, по одному на ключевую главу). Версии на C++17 —
основные; C11-версия существует там, где C-порт имеет смысл. Каждая программа:

- завершается `EXIT_SUCCESS` (0) только при полностью успешном прогоне и выводит в stdout финальную строку `ok: ...`;
- выводит любую диагностику в stderr и завершается `EXIT_FAILURE` (1) при ошибке;
- явно обрабатывает ожидаемые коды ошибок (`MDBX_KEYEXIST`, `MDBX_NOTFOUND`, `MDBX_BUSY`, ...), а не прерывается;
- использует только общие хелперы: `common/common.h++` и `common/common.h` (`common/common.c`).

### Сборка и запуск

Через CMake (все примеры зарегистрированы как CTest-тесты; запуск):

```sh
cmake -S . -B build -DMDBX_BUILD_CXX=ON -DMDBX_ENABLE_TESTS=ON
cmake --build build --target mdbx_ex_01-hello            # один пример
ctest --test-dir build -R '^mdbx_(ex_|config_store_)'    # все примеры учебника
```

Либо сборка одного примера вручную (точная команда указана в комментарии-заголовке каждого файла):

```sh
# C++ (для C++ хелперы — только заголовочные)
g++ -std=c++17 -I<каталог-заголовков-libmdbx> -Iexamples/common examples/c++/01-hello.c++ -lmdbx -o 01-hello
./01-hello

# C (требуется common/common.c)
gcc -std=c11 -I<каталог-заголовков-libmdbx> -Iexamples/common \
    examples/c/01-hello.c examples/common/common.c -lmdbx -o 01-hello
./01-hello
```

Замечания по платформам:
- Сборка под Windows через MinGW покрыта кросс-компиляционным CI-джобом
  (только компиляция: libmdbx отказывается делать mmap под Wine; запуск — на нативном Windows/WSL).
- Примеры, использующие `fork()`/порождение процессов и восстановление (`S15`, `S26`,
  `S27`), на Windows корректно деградируют: процесс-зависимые части пропускаются с сообщением, остальное выполняется.

### Локализация для docsite и учебников

Пер-локальные копии в `docs/{ru,en}/textbook/examples` (см. `make docsite` /
`make books`) генерируются из этого канонического дерева скриптом
[`docs/docsite/localize_examples.py`](../docs/docsite/localize_examples.py):

- комментарии с маркерами `// EN:`/`// RU:` отфильтровываются по локали, а маркер
  снимается («// RU: текст» → «// текст» в `ru`-копии и наоборот);
- прозу берём из пер-локальных переводов, лежащих рядом с каноническими
  файлами: `README.<locale>.md` для README-файлов (раздаются как
  `README.txt`) и `sample-bdb.ru.txt` для примера Berkeley DB в `ru`-копии.

Каноническое двуязычное дерево — единственный источник правды: CI собирает
и тестирует его как есть.
