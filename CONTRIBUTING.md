# Contributing to libmdbx

First off, thanks for taking the time to contribute! ❤️

All types of contributions are encouraged and valued.
However, this repository contains an automatically generated amalgamated version of the source code, intended for use and embedding, but not for _libmdbx_ development.
Therefore, we do not support development‑related processes here and do not accept changes, except for accepting issues and changes that apply exclusively to the amalgamated version, such as (for example) clarifications of this document.

If you are interested in libmdbx development or wish to contribute, you should use the **libmdbx-devel** repository.

> Nonetheles, if you like the project, but just don't have time to contribute, that's fine. There are other easy ways to support the project and show your appreciation, which we would also be very happy about:
> - Star the project
> - Tweet about it
> - Refer this project in your project's readme
> - Mention the project at local meetups and tell your friends/colleagues

The community looks forward to your contributions. 🎉
