# Документация libmdbx

**libmdbx** — встраиваемая транзакционная база данных «ключ-значение»:
компактная, очень быстрая (memory-mapped, B+tree, O(log N)), ACID, устойчивая
к сбоям по умолчанию, без WAL и без серверного процесса — безопасная для
конкурентного доступа из многих процессов.

  [ограничений и подводных камней](overview/restrictions.md)).
